# 레게톤 (Reggaeton) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: 레게톤 (Reggaeton)
- **BPM 범위**: 90~100 BPM
- **Key 가이드**: Minor keys
- **곡 구조**: Dembow rhythm, club-ready
- **카테고리**: reggaeton

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Modern Club Dembow** — dembow drums·808s·latin pop
2. **Hard Percussive Attack** — gritty bass·sharp drums·aggressive
3. **Romantic Latin Reggaeton Pop** — soft guitars·warm pads·smooth
4. **Tropical Summer Vibe** — beachy plucks·light percussion·sunny
5. **Electro Latin Fusion** — digital synths·modern FX·catchy

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

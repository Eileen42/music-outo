# 하드록 (Hard Rock) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: 하드록 (Hard Rock)
- **BPM 범위**: 120~160 BPM
- **Key 가이드**: Drop D, E minor, A minor
- **곡 구조**: Intro(짧게) → Verse → Chorus → Verse → Chorus → Bridge → Solo → Final Chorus
- **카테고리**: hard_rock

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Distorted Drive Anthem** — 디스토션·tom-driven·explosive
2. **Modern Power Groove** — down-tuned·gritty·halftime
3. **Metallic Speed Impact** — fast·chug riffs·anthemic
4. **Dark Riff Smasher** — palm-muted·atmospheric·dark
5. **Arena Headbanger** — stadium·thick rhythm·crowd-ready

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

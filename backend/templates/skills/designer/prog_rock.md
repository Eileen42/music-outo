# 프로그레시브록 (Progressive Rock) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: 프로그레시브록 (Progressive Rock)
- **BPM 범위**: varies (90~160 BPM, with shifts)
- **Key 가이드**: Modal, complex chord progressions
- **곡 구조**: Long form, multi-section, recurring themes, tempo changes
- **카테고리**: prog_rock

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Odd-Time Signature Journey** — odd time·layered·shifting moods
2. **Classical Fusion Epic** — classical motifs·long passages·emotional
3. **Mellotron Dreamscape** — vintage·finger-tapped·distinct movements
4. **Psychedelic Experiment** — swirling·hypnotic·ethereal
5. **Epic Multi-Part Storyline** — grand·narrative-driven·journey

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

# 얼터너티브록 (Alternative Rock) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: 얼터너티브록 (Alternative Rock)
- **BPM 범위**: 90~140 BPM
- **Key 가이드**: minor keys 자주
- **곡 구조**: narrow verses → wide distorted choruses
- **카테고리**: alt_rock

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Dreamy Emotional Drive** — chorus-drenched·airy·melancholic
2. **Indie Uplift Energy** — angular·groovy·syncopated
3. **Dark Mood Break** — moody·brooding·intimate→wide
4. **Synth-Driven Modern** — electronic·atmospheric·shimmering
5. **Raw Emotional Burst** — gritty·rebellious·emotional climax

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

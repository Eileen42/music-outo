# 블루스 (Blues) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: 블루스 (Blues)
- **BPM 범위**: 60~120 BPM
- **Key 가이드**: Minor pentatonic, blues scale
- **곡 구조**: 12-bar, call-and-response, soulful
- **카테고리**: blues

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Delta Root Vintage Blues** — raw acoustic·slide·gritty heartfelt
2. **Electric Chicago Blues Groove** — soulful leads·walking bass·expressive
3. **Slow Blues Emotional Ballad** — guitar bends·soft piano·heartfelt
4. **Funky Rhythm and Blues** — groovy riffs·horn accents·soulful
5. **Modern Blues Rock Fusion** — overdriven·tight drums·powerful

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

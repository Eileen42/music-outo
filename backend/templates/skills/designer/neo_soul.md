# 네오소울 (Neo Soul) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: 네오소울 (Neo Soul)
- **BPM 범위**: 70~95 BPM
- **Key 가이드**: 9ths, 11ths, modal
- **곡 구조**: Jazzy chords, swung drums, intimate
- **카테고리**: neo_soul

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Warm Rhodes Groove** — rhodes·soft bass·laid-back
2. **Dilla Swing Vibe** — swung drums·buttery·organic
3. **Ambient Soul Dream** — airy pads·soulful guitar·breathy
4. **Jazz Fusion Light Touch** — syncopated bass·tasteful·smooth
5. **Duet Soft Harmony** — call-and-response·minimal·warm

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

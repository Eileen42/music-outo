# 댄스팝 (Dance Pop) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: 댄스팝 (Dance Pop)
- **BPM 범위**: 118~128 BPM
- **Key 가이드**: Major keys, club-friendly
- **곡 구조**: Build → Drop format with clear hook
- **카테고리**: dance_pop

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Retro Disco Energy** — four-on-floor·funky disco·glossy retro
2. **Electric Party Highlight** — punchy loops·staccato·filtered builds
3. **Radio Hit Pop Groove** — bouncy·smooth top-line·summer
4. **EDM Pop Hybrid** — rising builds·vocal chops·festival
5. **City Nightclub Groove** — groovy bass·smooth waves·night-drive

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

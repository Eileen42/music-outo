# K-힙합 (Korean Hip-hop) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: K-힙합 (Korean Hip-hop)
- **BPM 범위**: 80~140 BPM
- **Key 가이드**: Minor, atmospheric
- **곡 구조**: Korean rap flow, melodic hooks, urban
- **카테고리**: k_hiphop

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Modern Melodic Hip-hop (Autotune)** — autotuned·atmospheric·warm
2. **Lo-fi Emotional Hip-hop (Chill Rap)** — lo-fi drums·jazzy rhodes·relaxed
3. **Hard Hit K-Drill** — sliding 808s·dark pads·stutter hi-hats
4. **Groovy Old-school Boombap** — dusty samples·jazz·rhythmic korean rap
5. **Trendy Cloud Hip-hop** — dreamy synths·floating·hazy melodic

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

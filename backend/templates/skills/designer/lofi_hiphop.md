# 로파이힙합 (Lo-fi Hip-hop) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: 로파이힙합 (Lo-fi Hip-hop)
- **BPM 범위**: 70~90 BPM
- **Key 가이드**: Jazzy minor 7ths
- **곡 구조**: Calm, study-friendly, vinyl warmth
- **카테고리**: lofi

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Warm Vinyl Chill Beat** — vinyl crackle·jazz chords·relaxed
2. **Late Night Coffeehouse** — dreamy pads·gentle keys·swinging
3. **Jazzy Calm Lounge** — smooth guitar·upright bass·dusty
4. **Retro Cassette Tape Vibe** — cassette filter·detuned·hazy
5. **Refreshing Daydream Float** — soft chimes·warm chords·crisp

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

# K-폰크 (Korean Phonk) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: K-폰크 (Korean Phonk)
- **BPM 범위**: 130~160 BPM
- **Key 가이드**: Minor, dark
- **곡 구조**: Phonk + Korean melodic hooks
- **카테고리**: k_phonk

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Reverie Dark Phase (K-Emo + Phonk Fusion)** — dark pads·drifting·phonk 808
2. **Running Car Dark Drive Synthwave Fusion** — synthwave elements·retro bass·reverb
3. **Hard Bass Trap + Korean Hook** — distorted bass·sharp hi-hats·emotional hooks
4. **Emotional Future Phonk (Soft Phonk + K-R&B)** — smooth pads·mellow bass·dreamy autotuned
5. **Dark Lo-fi + Deep Voice Korean Smoke Tone** — smoky deep·tape texture·slow drifting

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

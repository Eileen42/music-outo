# J-팝 (J-pop) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: J-팝 (J-pop)
- **BPM 범위**: 110~145 BPM
- **Key 가이드**: Bright Major keys
- **곡 구조**: Anime-style energy, soaring chorus
- **카테고리**: j_pop

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Upbeat Animation Pop** — major-key·fast electronic·playful
2. **Refresh Ballad Fusion** — clean arpeggios·warm pads·heartfelt
3. **Otaku Kitsch Pop** — bouncy·quirky FX·energetic
4. **Cinematic Archive Style** — lush strings·soft piano·anime-grandeur
5. **Hyper-Tempo Electro Pop** — sharp leads·rapid drums·idol

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

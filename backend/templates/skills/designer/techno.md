# 테크노 (Techno) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: 테크노 (Techno)
- **BPM 범위**: 125~140 BPM
- **Key 가이드**: Minor, modal
- **곡 구조**: Pounding kicks, hypnotic, minimal evolution
- **카테고리**: techno

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Dark Underground Drive** — pounding kicks·hypnotic loops·cold
2. **Industrial Hard Tech** — distorted kicks·metallic·gritty
3. **Melodic Techno Spacescape** — emotional arpeggios·warm pads·deep bass
4. **Minimal Tech Groove** — tight drums·rhythmic clicks·evolving
5. **Old School Rave Techno** — 90s synth stabs·rolling bass·energetic

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

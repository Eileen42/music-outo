# K-팝 (K-pop) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: K-팝 (K-pop)
- **BPM 범위**: 85~130 BPM (varies)
- **Key 가이드**: Major/Minor mix, Korean-style harmonies
- **곡 구조**: Verse → Pre-chorus build → Chorus drop, with rap break
- **카테고리**: kpop

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Trendy Hybrid Pop-Trap** — trap beats·sharp stabs·rap-vocal switches
2. **Emotional R&B Pop Fusion** — smooth r&b·lo-fi·airy female
3. **Cinematic Pre-Chorus Buildup** — atmospheric pads·emotional progressions·wide synth
4. **Powerful Dance Performance** — punchy electronic drums·rhythmic vocal·choreography
5. **Ballad EDM Hybrid** — soft verses·soaring chorus·shimmering

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

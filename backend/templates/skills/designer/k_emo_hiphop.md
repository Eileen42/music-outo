# 이모힙합 (Korean Emo Hip-hop) — 채널 컨셉 가이드

## Designer 역할
이 채널의 **전체 음악적 방향성**을 정한다 — 곡별 디테일은 Composer 가 담당.

## 채널 정체성
- **장르**: 이모힙합 (Korean Emo Hip-hop)
- **BPM 범위**: 70~95 BPM
- **Key 가이드**: Minor, melancholic
- **곡 구조**: Sad guitar + autotuned vocals + 808s
- **카테고리**: k_emo_hiphop

## 5가지 무드 라벨 (Composer 가 곡별로 선택)
1. **Emotional Guitar + Melodic Rap** — sad clean guitar·atmospheric·autotuned
2. **Dark Reverie Night Mood** — moody synths·deep bass·reverb-heavy
3. **Pure Emotion Guitar Drop** — bright plucked·soft drums·warm bass
4. **Low-tone Tension + Deep Rap** — slow-building·emotional rap·ambient
5. **Husky Vocal + Dark Trap Mix** — husky·dark trap·dramatic

## 곡 분포 가이드 (예: 20곡 채널)
다섯 무드를 적절히 섞어 단조로움 방지. 권장 비율은 채널 컨셉에 맞게 조정:
- 대표 무드 1개 → 30~35%
- 보조 무드 2개 → 각 20%
- 변주 무드 2개 → 각 12~15%
- 클라이맥스 트랙: 3~5곡 간격으로 배치

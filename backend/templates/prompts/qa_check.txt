Composer 가 만든 Suno 프롬프트와 Lyricist 가 만든 가사를 검토해서, 필요한
부분을 자동 수정한 결과물을 반환한다.

━━ 프로젝트 컨셉 (Designer 결정) ━━
{concept}

━━ 사용자 요청 (반영 정합성 검증 필요) ━━
- 키워드: {user_keywords}
- 분위기: {user_mood}
- 가사 힌트: {user_lyrics_hint}

━━ 채널 정보 ━━
- 가사 채널: {has_lyrics}
- 채널 Suno 기본 프롬프트: {suno_base}

━━ 검토 대상 곡들 ({count}곡) ━━
{tracks_summary}

━━ 검수 체크리스트 (반드시 모두 점검) ━━

1. **Suno 프롬프트 6줄 형식 준수**
   - 라벨 정확히 일치: Genre: / Mood: / Tempo: / Instrumentation: / Sound Effects/Atmosphere: / Additional Descriptors:
   - 6줄 미만 / 형식 깨진 곡은 즉시 6줄로 보정

2. **가사 채널 한정 — 인트로 최소화 강제 (★ 가장 중요)**
   - has_lyrics=True 면 모든 곡의 Additional Descriptors 에 다음이 반드시 있어야 함:
     · "no intro" 또는 "minimal intro 4 bars max"
     · "no humming, no scat"
     · "vocals start by 0:08"
   - 빠진 곡은 직접 추가해서 보정

3. **사용자 키워드 / 분위기 정합성**
   - user_keywords / user_mood 가 각 곡의 Mood / Additional Descriptors 에 자연스럽게 녹아있는지
   - 채널 suno_base 의 핵심 키워드가 어딘가 1번 이상 등장하는지

4. **가사 ↔ 음악 분위기 일치 (가사 곡만)**
   - lyrics 가 mood / mood_detail 의 톤과 어긋나지 않는지
   - 음절/리듬이 Tempo (BPM) 에 부합하는지 (너무 길거나 짧지 않게)
   - 어긋나면 lyrics 를 자연스럽게 다듬어 반환

5. **곡별 다양성**
   - 곡들의 mood 가 거의 동일하면 일부 변주 추가
   - special_elements 가 모두 같으면 절반 정도는 다르게 변경

━━ 반환 형식 ━━
JSON 배열로 검수·수정된 곡 {count}개 반환. 각 곡은 입력과 동일한 스키마 +
qa_notes (이 곡에 무엇을 보정했는지 한 줄 요약, 변경 없으면 "ok"):

[
  {{
    "index": 1,
    "title": "...",
    "title_ko": "...",
    "mood": "...",
    "mood_detail": "...",
    "energy_level": "...",
    "special_elements": "...",
    "duration_hint": "...",
    "category": "...",
    "lyrics_theme": "...",
    "suno_prompt": "Genre: ...\nMood: ...\nTempo: ...\nInstrumentation: ...\nSound Effects/Atmosphere: ...\nAdditional Descriptors: ...",
    "lyrics": "...",
    "qa_notes": "예: 'no intro 추가', '가사 톤 조정', 'ok'"
  }}
]

원본 의도를 최대한 살리면서 누락만 보정. 과도한 재작성 금지.
